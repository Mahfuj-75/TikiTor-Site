Tikitor website
===============
Open index.html in a browser to view the site.

Files
  index.html      page content (Home, How it works, For organizers, footer/contact)
  css/style.css   all styling; brand colours are at the top (:root)
  js/script.js    page switching, mobile menu, sample QR drawing
  assets/         logos (transparent PNG) and organizer portal screenshots

Pages are switched with the URL hash: #home, #how-it-works, #for-organizers, #contact.
Put your QR code link as: https://your-domain/#home (or index.html).

Contact details (email, phone, WhatsApp, address) are inside <footer id="contact"> in index.html.
